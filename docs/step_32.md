# Step 32 — New Topic Button in Recents

1. Problem being solved in this step: When recent topics are shown, it is not obvious how to start a completely new topic.
2. Proposed technical solution: Add a “New topic” button under the recent topics list.
3. Implementation plan: Extend the recent topics keyboard with a `recent:new` button and show the topic prompt when pressed.
4. Example code or pseudocode (if relevant): `recent:new -> format_topic_prompt()`.
5. Risks and edge cases: None; user can still type directly.
6. Suggested next improvements: Add a “Clear recent topics” option.
